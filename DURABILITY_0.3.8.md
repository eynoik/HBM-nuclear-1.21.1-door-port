# 0.3.8 durability normalization

All 15 ported doors now share the same durability profile:

- destroy time / hardness: `60`
- explosion resistance: `1500`
- correct tool required for drops
- pickaxe mineable

This intentionally replaces the wildly different legacy HBM values with one gameplay-oriented profile that is only modestly tougher than obsidian, as requested.
